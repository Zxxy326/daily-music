## 五、下一优先级

1. **分 ABI 打包 + GitHub 分发** ✅ 已完成：32/64 位各出一个独立 APK（`tv-v1.0.8` release），32 位包补齐 `libkugou_server.so`，README 增 TV 版介绍
1. **手机端三种歌词动效移植 TV** ✅ 已完成（v1.0.8）：WAVE 动感涟漪（封面取色 + 频谱驱动波带）、KTV 简约（描边歌名 + 两句逐字点亮）、CLOCK 精简时钟；播放页工具行「歌词动效」进入，遥控器左右键切换。辅助函数（取色/token化/扫色/描边字）在 `TvLyricEffects.kt` 自带，避免跨模块依赖 app。
1. **MuMu 模拟器联网实测 + 交互修复** ✅ 已完成（v1.0.9）：在 MuMu Player 12（x86_64 / Android 12）联网安装 32 位 debug 包，三种动效渲染全部截图验证通过（封面取色/波带/描边/时钟均正常）。过程中发现并修复三个 bug：① 播放页工具胶囊因 `Box(fillMaxSize)` 在 Row 全宽约束下互相重叠只露一个 → ToolChip 固定 96dp 宽，5 个横排正常；② 效果切换方向键跳 2 格（tab 双焦点目标 + Box.onKeyEvent 重复改 index）→ 改纯焦点驱动，一次一格；③ 效果页返回键失效（焦点 tab 消费 Back，BackHandler 收不到）→ 最外层 `onPreviewKeyEvent` 拦截 Back。为适配 MuMu 的 Android 12 临时把 minSdk 降到 32 构建测试包，验证后已恢复 33。
2. ~~16KB page size 适配~~ —— **用户决定不做**：电视绝大多数是 32 位系统，本项目主要面向电视；64 位包在 Android 15+ 上的 16KB 分页告警不影响 32 位设备，且已通过分 ABI 隔离，老盒子用 32 位包即可
3. **细节补测**（可选）：扫码登录态流转（需手机酷狗真扫）、签到、队列跳歌等需登录/真机交互的场景
4. TV 功能侧 A/B/C 三组 + 首页推荐流已全部落地并完成真机联网验证；D 组已决策（识曲/评论砍掉，歌词开关已接入），功能开发收尾
